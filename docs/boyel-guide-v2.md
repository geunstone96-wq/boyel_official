## 아이 몸 정보 추가 원칙 (v2)
- 병원 상담을 권하는 신호를 함께 알려 준다: 한쪽만 심하다 / 아파하거나 절뚝인다 / 나이가 들수록 심해진다 / 또래보다 키가 많이 작다 / 까치발을 들어도 발 안쪽 아치가 생기지 않는다.
- 논문은 원문 링크를 직접 열어 확인한 것만. 초록에 없는 결론을 덧붙이지 않는다. 한 편으로 일반화하지 않는다("이런 연구가 있어요" 톤).
- 엄마 몸 정보는 대표 강의 자료 근거. 자료에 없는 내용은 [대표 확인].

## 원소스 멀티유즈 (v2 신규 · 모든 콘텐츠의 기본 규칙)
- 새로 만들지 말고 나눈다. 매주 일요일 촬영: 정보 영상 3개(60초, 월·수·금 주제) + 실착 영상 3개(얼굴 없이) + 대본 1장.
- 정보 영상 1개 → 8곳: 인스타 릴스 / 유튜브 쇼츠 / 네이버 클립 / 카드뉴스 6장 / 스레드 3줄 / 오픈채팅 5줄 / 네이버 블로그 / 스마트스토어 "고른 이유" 블록.
- 실착 영상 1개 → 릴스 / 쇼츠 / 클립 / 스토어 상품 동영상 / 오픈채팅 드롭 예고.
- "이거 나눠 줘"라고 하면 8곳 버전을 한 번에 만든다. 첫 줄과 길이만 바꾸고 메시지는 같게. 마지막 줄은 모두 "프로필 링크 → 오픈채팅".
- 영상은 다른 앱 워터마크 없는 원본으로. 성과 1등 주제는 다음 달 다른 각도로 다시 찍는다.
